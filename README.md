# 테마 레이더 — 장전 관찰후보 자동 생성 (Phase 1)

밤사이 미국장에서 오른 테마를 같은 결의 국내 종목으로 넘기고, 국내 뉴스·공시에서 뜨는 테마를
찾아 **장 시작 전에** 관찰 후보를 만든다. 사후 급등 정리판이 아니라 앞서보기(forward)다.

**매매 추천 도구가 아니다. 주문 기능이 없고, 앞으로도 넣지 않는다.**
최종 매수·매도 판단과 실행은 사용자가 직접 한다.

---

## 매일 아침 뭐가 나오나

평일 **07:30**에 자동으로 돌고 두 개가 갱신된다.

| 파일 | 내용 |
|---|---|
| `out/index.html` | 신문 브리핑형 대시보드 (최신). 날짜별로 `out/2026-08-10.html`도 남는다 |
| `out/latest.txt` | 3~5줄 요약 리포트 |

대시보드 구성 — 제호 · 글로벌 기준선 · **결론(해외발/국내발 두 칸)** · **오늘의 픽** ·
해외발 테마 / 국내발 테마 / 반복급등·회피 3컬럼. PC는 3컬럼, 모바일은 1컬럼으로 접힌다.

## 직접 돌리기

```bash
python run_morning.py --skip-seed
```

시드 엑셀을 새로 넣었으면 `--skip-seed` 없이 돌린다(전체 재적재).

## 파이프라인

```
seed_import   무지랭이 폴더의 수기 엑셀 26개 → 테마 지도 490종목 / 79테마 / 217 테마일자
     ↓
collect_us    Yahoo → 다우·S&P·나스닥·SOX·EWY·원달러·코스피/코스닥
              + 미국 테마 바스켓 13개 등락(중앙값)과 주도주
     ↓
collect_news  매경·연합 RSS + DART 공시 → 테마·방향(호재/악재/죽은테마) 추출
     ↓
screen        네이버 일봉 → MA·ATR·거래대금 → 필터 통과분만 '픽',
              진입가·손절선·목표가·손익비 세트 생성
     ↓
report / dashboard
```

## 후보가 픽이 되는 조건

전부 통과해야 픽이다. 하나라도 걸리면 풀에 남는다.

- **자리**: 정배열 돌파 또는 눌림목 지지 시도 (과열·역배열은 탈락)
- **손익비** 1.5 이상
- **유동성**: 20일 평균 거래대금 30억 이상
- **거래**: 당일 거래량이 20일 평균의 0.8배 이상
- **리스크**: 관리종목·투자경고 제외

진입가는 호가단위로 정렬해서 나온다. **차트 데이터가 없으면 픽으로 올리지 않고
`차트 확인 필요`로 풀에만 둔다** — 근거 없이 진입가를 만들어 붙이지 않는다.

픽이 0개인 날도 정상이다. 자리가 없으면 관망이 결론이다.

## 손봐야 할 곳

| 파일 | 용도 |
|---|---|
| `config/themes.json` | 테마 단일 소스. 미국티커↔국내종목↔뉴스키워드 |
| `config/watchlist.json` | **핵심 관심리스트 — 비어 있다. 직접 채울 것** |
| `config/theme_aliases.json` | 엑셀·뉴스의 테마 표기 → 표준 테마명 |
| `config/stock_aliases.json` | 사명 변경·오타 보정. `_unresolved`는 미확인 목록 |
| `config/signal_lexicon.json` | 호재/악재/죽은테마/반전 판정 단어 |
| `config/news_sources.json` | RSS 목록. 한경은 403이라 꺼둠 |
| `src/screen.py` 상단 | `MIN_RR`, `MIN_VALUE_EOK`, `OVERHEAT`, `MAX_STOCKS_PER_THEME` |

`MAX_STOCKS_PER_THEME`(현재 80)는 테마당 일봉을 받을 종목 수다. 이 수를 넘겨 잘린 종목이
생기면 몇 종목이 빠졌는지 리포트와 대시보드 하단에 찍힌다 — 조용히 잘리지 않는다.

> 임계값은 **하루 결과만 보고 바꾸지 말 것.** 최소 3/5/10/20 거래일 성과를 쌓고 판단한다(Phase 3).

## 뉴스 판정을 더 좋게 하려면

규칙 층은 무인증 RSS만 보고 항상 돌지만, 순환매 방향이나 정책 수혜 추론까진 못 한다.
LLM이 읽은 결과를 JSON으로 얹을 수 있다.

```bash
python src/ingest_signals.py signals.json && python run_morning.py --skip-seed
```

형식은 `src/ingest_signals.py` 상단 참고. **근거 URL이 없는 신호는 받지 않는다.**

## 자동 실행 관리

```bash
schtasks /Query /TN "ThemeRadar-장전브리핑"
```

끄려면 `/Delete /F`, 시간 바꾸려면 `/Change /ST 07:00`.
실행 로그는 `logs/run_YYYYMM.log`, 실패는 `logs/errors.log`.

## 범위 밖 (의도적으로 안 넣음)

- 주문 API·자동매매·매수/매도 버튼
- 장중 실시간 호가·체결·분봉 VWAP — 일봉/종가 레벨만 다룬다
- 코스피200 야간선물: 무료 소스가 없어 **EWY로 대체**하고 부재를 명시한다

## 알려진 한계

- 뉴스 테마 배정은 규칙 기반이라 오배치가 남는다. 대시보드에 **근거 기사 제목과 링크를
  항상 같이 띄우는 이유** — 이상하면 원문으로 바로 확인하라는 뜻이다.
- 종목코드 미매칭 11건(사명 변경·상장폐지 추정)은 `stock_aliases.json`의
  `_unresolved`에 있다. 추측으로 채우지 않았다.
- 성과 추적(`outcomes` 테이블)은 스키마만 있고 Phase 3에서 채운다.
