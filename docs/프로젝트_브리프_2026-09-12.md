# 테마 레이더 프로젝트 브리프 (2026-09-12 기준, 외부 AI 검토용)

## 1. 목적과 제약
- 직장인 개인 투자자용 **장전 관찰후보 자동화** 시스템. 장중 실시간 대응이 불가능하므로 "저녁에 확인 → 아침에 예약주문(진입·손절)" 흐름에 맞춰 설계.
- 시스템은 **매수 추천을 하지 않는다**. 규칙에 맞는 관찰 후보와 시나리오(진입가·손절가·목표가)만 내고, 판단·실행은 사람이 한다. 주문 API·자동매매는 없다.
- 계좌는 토스증권(공식 개인용 API 없음). 시세는 네이버 일봉(장중 갱신 없음), 미국·원자재는 야후 일봉, 공시는 DART 오픈API(사용자 키), 수급은 네이버 모바일 API.

## 2. 파이프라인
1. **미국장 테마 바스켓**: 13개 테마 × 50티커(데이터센터 전력·광통신·AI 반도체·로봇·양자·원전·이차전지 등)의 간밤 등락 중앙값 → 어느 테마가 올랐나.
2. **한국 테마 지도**: 821종목·110테마. 일별 '테마별 상승종목' 엑셀(사람이 매일 정리)을 시드로 누적하고, 수동 보강(map_extra)과 동행 학습(learn_comove: 테마 급등일에 같이 오르는 지도 밖 종목)으로 확장.
3. **자리 조건(A급)**: 60일 고점 대비 −15~−3%, 20일 이격 0.95~1.20, RSI14 45~75, 거래대금 20일 30억 이상.
4. **시나리오**: 진입 = 전일 고가×1.002 돌파(갭이면 시가), 손절 1.5×ATR14, 목표 +2R, 20일 기한, 동시 터치는 손절 우선. 리스크 1%/건, 종목당 20% 상한, 왕복 비용 0.3%.
5. **발행**: 평일 07:25 GitHub Actions(클라우드) + 07:22 로컬 백업이 브리핑과 현황판(GitHub Pages, 12개 시트)을 생성. 저녁에 로컬에서 채점·복기.
